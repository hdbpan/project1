# 餐厅点餐系统

基于 Flask + MySQL + Bootstrap 5 的现代化餐厅点餐管理系统

## 功能特性

### 顾客端功能
- ✅ 用户注册与登录
- ✅ 浏览菜单（分类筛选、搜索）
- ✅ 购物车管理
- ✅ 在线下单（选择桌台、备注）
- ✅ 订单查询与跟踪
- ✅ 多种支付方式
- ✅ 订单取消

### 管理员功能
- ✅ 管理员仪表盘（数据统计）
- ✅ 菜品管理（增删改查）
- ✅ 订单管理（状态更新）
- ✅ 用户管理
- ✅ 热销菜品统计
- ✅ 营业额统计

### 技术特点
- ✅ 使用存储过程处理复杂业务逻辑
- ✅ 触发器自动维护数据一致性
- ✅ 视图简化复杂查询
- ✅ 完整的数据完整性约束
- ✅ RESTful API设计
- ✅ 响应式界面设计

## 技术栈

- **后端**: Flask 3.0 + Python 3.8+
- **数据库**: MySQL 8.0+
- **前端**: Bootstrap 5 + jQuery
- **图标**: Bootstrap Icons
- **身份验证**: Flask-Login
